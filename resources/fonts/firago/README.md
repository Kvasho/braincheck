# FiraGO

Self-hosted UI font (Georgian + Latin in one design).

- Source: https://github.com/bBoxType/FiraGO (release 1.000, `Fonts/FiraGO_WEB_1001/Roman`)
- Licence: SIL Open Font License 1.1, see `OFL.txt`
- Weights shipped: 400 (Regular), 500 (Medium), 600 (SemiBold), 700 (Bold) — only the weights the UI uses.
- Files verified against the upstream git blob hashes when added.
